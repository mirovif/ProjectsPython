# Данные

Источник: [Ames Housing](https://jse.amstat.org/v19n3/decock/AmesHousing.txt).
Точный снимок и SHA-256: [source.json](source.json).
`run.py` загружает данные в `raw/`, проверяет digest и переиспользует cache.
Исходный датасет не добавляется в Git и в архив портфолио; повторный запуск загружает его из источника.
Графики и таблицы являются результатами обработки этих данных.
Данные сохраняют условия использования первичного источника.
