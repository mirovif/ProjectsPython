# Apartment Price Prediction · Regression

**Оценка цены жилья с воспроизводимым ML pipeline.**
Выбранная по CV модель — **Gradient Boosting**: test RMSE **$25,054**, MAE **$14,968**, R² **0.922**.
Это фактический запуск, а не предполагаемые значения.

## Задача и данные

Предсказать цену продажи по известным характеристикам объекта: площади, качеству,
району, возрасту здания и инфраструктуре. В качестве открытого набора использован
**Ames Housing**: 2,930 реальных продаж жилой недвижимости в Ames, Iowa, 2006–2010.
Target — `SalePrice`, в долларах США периода сделки; площадь измеряется в sq ft.

Несмотря на название проекта, этот датасет описывает преимущественно **дома, а не квартиры**.
Он позволяет продемонстрировать регрессионный pipeline, но не подтверждает качество
оценки квартир в другом городе или на современном рынке.

- [Первичный источник и описание автора — Dean De Cock](https://jse.amstat.org/v19n3/decock.pdf)
- [Оригинальные данные TSV](https://jse.amstat.org/v19n3/decock/AmesHousing.txt)
- [Словарь признаков](https://jse.amstat.org/v19n3/decock/DataDocumentation.txt)
- SHA-256 зафиксирован в [data/source.json](data/source.json); данные скачиваются скриптом и не коммитятся.

## Подход и защита от leakage

1. Сначала выделен test 20%: **2344 train / 586 test**, `random_state=42`.
2. EDA, missing values и корреляции рассчитаны только на train. Все 75 исходных pre-sale признака
   передаются в модели; корреляции показаны для объяснения, а не для выбора по test.
3. Удалены `Order`, `PID` и target. Также исключены `Sale Type`, `Sale Condition`, `Mo Sold`, `Yr Sold`,
   поскольку сведения о фактической сделке не должны требоваться при предварительной оценке.
4. Числовые пропуски заполняются медианой, добавляется missing indicator, затем StandardScaler.
   Для деревьев масштабирование не требуется, но общий preprocessing упрощает честное сравнение.
5. Для категорий — Unknown для неизвестного значения, one-hot и объединение редких категорий.
   `MS SubClass` — код класса объекта, поэтому трактуется как категория. `NA` в исходном словаре часто
   означает отсутствие объекта (например, подвала), а пустая ячейка — неизвестное значение: они различаются.
6. Imputer, scaler и encoder находятся внутри `Pipeline` и заново обучаются в каждом CV fold.
7. **3-fold KFold**, shuffle, seed 42; небольшие сетки параметров. Модель выбрана по минимальному CV RMSE.
   После выбора один раз оценены все зафиксированные модели на test. Выбор по test не выполнялся.

Дорогие объекты и большие ошибки не удалялись из test. Точные параметры и все CV-кандидаты
сохранены в [reports/](reports/); параметры победителя: `{"model__learning_rate": 0.05, "model__max_depth": 3}`.

## Модели и метрики

Baseline предсказывает медиану train. Ridge — линейная регрессия с L2-регуляризацией,
которая стабилизирует коэффициенты при коррелирующих площадях и one-hot признаках.
Decision Tree показывает ограничения одиночного дерева; Random Forest снижает его вариативность;
Gradient Boosting последовательно исправляет ошибки слабых деревьев.

Основная метрика **RMSE** сильнее штрафует большие ошибки в цене. **MAE** показывает средний
абсолютный промах в USD и проще интерпретируется. **MSE** дан в USD²; **R²** сравнивает модель
с предсказанием среднего test-target и может быть отрицательным.

| Модель | CV RMSE ± std, USD | Test MAE, USD | Test MSE, USD² | Test RMSE, USD | Test R² |
| --- | --- | --- | --- | --- | --- |
| Median baseline | 79,376 ± 2,237 | 63,838 | 8,896,757,562 | 94,323 | -0.110 |
| Ridge regression | 31,256 ± 6,087 | 16,729 | 846,327,891 | 29,092 | 0.894 |
| Decision Tree | 36,121 ± 2,111 | 22,340 | 1,191,141,619 | 34,513 | 0.851 |
| Random Forest | 27,556 ± 3,324 | 15,653 | 706,189,264 | 26,574 | 0.912 |
| Gradient Boosting | 25,146 ± 4,313 | 14,968 | 627,706,442 | 25,054 | 0.922 |

CV std — вариация между тремя folds, **не доверительный интервал**. CV использовалась для
подбора параметров, поэтому её лучший score может быть оптимистичным; test остаётся отдельной оценкой.

![Важность исходных признаков](images/feature_importance.png)

Permutation importance измеряет изменение RMSE при перемешивании исходного признака,
5 повторов, seed 42; error bars показывают std повторов. Коррелирующие признаки могут
делить importance, поэтому это не причинный эффект и не основание автоматически удалить признаки.
После этого анализа модель не переобучалась по test.

В этом запуске сильнее всего влияет `Overall Qual`: его перемешивание увеличивает RMSE
примерно на $25,905; для `Gr Liv Area` — на $13,435. В дорогом квартиле MAE около $24,880,
против $9,452 во втором квартиле. Среди самых больших ошибок есть объект площадью
4,676 sq ft: actual $184,750, predicted $436,381. Такие случаи оставлены в оценке и
показывают, почему одного среднего score недостаточно.

## Результат и выводы

По CV выбран Gradient Boosting. Его holdout RMSE ниже медианного baseline на **73.4%**.
Сравнение отражает одну фиксированную выборку: преимущество на ней не гарантирует
такого же результата в другой местности. Нелинейные модели могут использовать взаимодействия
между качеством, площадью и районом; сравнение scores само по себе не доказывает эту причину.

Следующий эксперимент: временная проверка на продажах более позднего года, отдельная оценка
редких типов объектов, сравнение `log1p(target)` по CV и простые интервалы ошибки.
Для этого потребуется новый протокол валидации; текущий test после изучения ошибок не подходит
для дальнейшего подбора параметров. Модель не учитывает современную инфляцию и новые города.

## Воспроизведение

Python 3.12; запуск из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pytest -q
python run.py
python predict.py example_input.csv --output predictions.csv
```

В Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\Activate.ps1`.

Для первой загрузки нужен интернет. SHA-256 проверяется и для скачанного, и для cached файла.
`example_input.csv` содержит первые три строки признаков train без target; это проверка интерфейса,
а не дополнительная оценка качества. Вход для inference — CSV с теми же именами исходных признаков.
Запуск сохраняет модель в `models/best_model.joblib`, таблицы в `reports/`, графики в `images/`.
Версии и split записаны в summary; выполнение занимает несколько минут и зависит от компьютера.
Notebook [analysis.ipynb](notebooks/analysis.ipynb) читает те же артефакты и показывает EDA и ошибки.
Для интерактивного открытия notebook можно отдельно установить `jupyter`.

```text
├── src/housing/
├── tests/
├── notebooks/
├── data/
├── reports/
├── images/
├── run.py
└── predict.py
```
