# Titanic Survival Classification

Предсказание выживания пассажиров Titanic по возрасту, полу, классу билета и другим данным.
Сравниваются четыре модели и базовый прогноз. По кросс-валидации выбран Random Forest;
его ROC-AUC на тестовой выборке — 0.808.

## Данные

891 пассажир из обучающего набора [Kaggle Titanic](https://www.kaggle.com/c/titanic/data).
CSV загружается из [репозитория seaborn](https://github.com/mwaskom/seaborn-data/blob/master/raw/titanic.csv).
Целевая переменная — `survived`: 1 — пассажир выжил, 0 — погиб.
Источник и контрольная сумма файла находятся в [data/source.json](data/source.json).

## Признаки и подготовка

Используются возраст, пол, класс, стоимость билета, порт посадки и число родственников.
Из них рассчитываются размер семьи, признак одиночного путешествия и стоимость билета
на человека. Из имени извлекается обращение: `Mr`, `Mrs`, `Miss`, `Master` или `Other`.
Полное имя в модель не передаётся.

Числовые пропуски заполняются медианой, добавляются индикаторы пропусков и масштабирование.
Категории кодируются через one-hot; класс билета тоже считается категорией.
Обработка признаков выполняется внутри `Pipeline` на каждой обучающей части.

## Проверка качества

711 пассажиров используются для обучения, 180 — для теста; `random_state=42`.
Разделение выполнено через `StratifiedGroupKFold`: пассажиры с одним номером билета
попадают в одну часть. При подборе параметров на обучающих данных используется
та же группировка и три разбиения.

Модель выбирается по ROC-AUC: эта метрика оценивает ранжирование вероятностей.
Для остальных метрик вероятность от 0.5 считается прогнозом выживания.
Precision показывает долю выживших среди таких прогнозов, recall — долю найденных
выживших, F1 объединяет эти две оценки. Accuracy сравнивается с базовым прогнозом
самого частого класса, который здесь всегда предсказывает гибель.

| Модель | CV ROC-AUC ± std | Test Accuracy | Test Precision | Test Recall | Test F1 | Test ROC-AUC |
|---|---|---|---|---|---|---|
| Majority baseline | 0.500 ± 0.000 | 0.622 | 0.000 | 0.000 | 0.000 | 0.500 |
| Logistic Regression | 0.882 ± 0.023 | 0.756 | 0.694 | 0.632 | 0.662 | 0.763 |
| Decision Tree | 0.867 ± 0.022 | 0.728 | 0.651 | 0.603 | 0.626 | 0.740 |
| Random Forest | 0.889 ± 0.020 | 0.756 | 0.700 | 0.618 | 0.656 | 0.808 |
| Gradient Boosting | 0.883 ± 0.017 | 0.750 | 0.677 | 0.647 | 0.662 | 0.800 |

`std` — разброс между тремя разбиениями.
В выбранном Random Forest 160 деревьев, `min_samples_leaf=5`, глубина не ограничена.
Параметры и метрики записаны в [summary.json](reports/summary.json).

## Ошибки модели

![Матрица ошибок](images/confusion_matrix.png)

При пороге 0.5 модель правильно определила 94 погибших и 42 выживших.
18 погибших отнесены к выжившим, 26 выживших — к погибшим: пропущены 26 из 68 выживших.
Прогнозы и вероятности сохранены в [test_predictions.csv](reports/test_predictions.csv).

![Важность признаков](images/feature_importance.png)

Важность измеряется изменением ROC-AUC после перемешивания признака.
`name` на графике соответствует обращению, извлечённому из имени.
Расчёты находятся в [permutation_importance.csv](reports/permutation_importance.csv).

ROC-AUC снижается с 0.889 на кросс-валидации до 0.808 на тесте.
Доля ошибок на тесте — 32.3% для женщин и 20.0% для мужчин;
в этих группах 65 и 115 пассажиров соответственно.
Для следующего эксперимента стоит повторить групповую кросс-валидацию
и выбрать порог на отдельной проверочной части. Результаты в таблице относятся к локальному тесту.

## Запуск

Python 3.12. Команды для PowerShell из папки `titanic-survival-classification`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -q
python run.py
python predict.py example_input.csv --output predictions.csv
```

В Linux и macOS окружение активируется командой `source .venv/bin/activate`.

`run.py` загружает данные, обучает модели и сохраняет графики и отчёты.
Для первой загрузки нужен интернет. Выбранная модель записывается в `models/best_model.joblib`.
`predict.py` принимает CSV с исходными признаками; в `example_input.csv` есть три строки для проверки запуска.
