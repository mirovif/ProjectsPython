# Артефакты реального запуска

- `summary.json`: выбранная по CV модель, seed, размер split, конфигурация и версии.
- `model_comparison.csv`: CV и итоговая holdout-оценка всех моделей.
- `*_cv.csv`: полный небольшой grid search, включая вариацию между folds.
- `split.csv`: исходные индексы строк и их принадлежность train/test.
- `missing_train.csv`, `eda_train.csv`: первичный анализ только обучающей части.
- `test_predictions.csv`: фактические метки/цены, предсказания и ошибки.
- `permutation_importance.csv`: зависимость качества от исходных признаков.

`python run.py` пересоздаёт эти результаты и графики. `elapsed_seconds`
зависит от компьютера. Подробности протокола и интерпретация находятся в README.
