# ML Metrics From Scratch

Реализация метрик регрессии и бинарной классификации на Python и NumPy.
Функции находятся в [metrics.py](src/ml_metrics/metrics.py), примеры расчёта — в [examples.py](examples.py).
Результаты сравниваются с `sklearn.metrics`.

## Регрессия

`y` — реальные значения, `ŷ` — прогнозы, `n` — число наблюдений.

| Метрика | Формула | Значение |
|---|---|---|
| MAE | `sum(abs(y − ŷ)) / n` | Средняя абсолютная ошибка |
| MSE | `sum((y − ŷ)²) / n` | Средняя квадратичная ошибка |
| RMSE | `sqrt(MSE)` | Ошибка в единицах исходной величины; большие промахи влияют сильнее |
| R² | `1 − sum((y − ŷ)²) / sum((y − mean(y))²)` | Качество относительно прогноза средним значением; может быть отрицательным |

Пример из `examples.py`:

```python
y_true = [3., -.5, 2., 7.]
y_pred = [2.5, 0., 2., 8.]
```

Абсолютные ошибки — `[0.5, 0.5, 0, 1]`: MAE = `(0.5 + 0.5 + 0 + 1) / 4 = 0.5`.
Сумма квадратов ошибок — 1.5, поэтому MSE = `1.5 / 4 = 0.375`, RMSE ≈ 0.612372.

| Метрика | Результат | scikit-learn |
|---|---:|---:|
| MAE | 0.500000 | 0.500000 |
| MSE | 0.375000 | 0.375000 |
| RMSE | 0.612372 | 0.612372 |
| R² | 0.948608 | 0.948608 |

## Бинарная классификация

Функции принимают метки 0 и 1. Положительный класс — 1.
TP и TN — правильные прогнозы классов 1 и 0; FP и FN — ложноположительные и ложноотрицательные.

| Метрика | Формула | Значение |
|---|---|---|
| Accuracy | `(TP + TN) / n` | Доля правильных прогнозов |
| Precision | `TP / (TP + FP)` | Доля верных среди положительных прогнозов |
| Recall | `TP / (TP + FN)` | Доля найденных объектов положительного класса |
| F1 | `2TP / (2TP + FP + FN)` | Гармоническое среднее precision и recall |

```python
y_true = [1, 0, 1, 1, 0, 1]
y_pred = [1, 0, 0, 1, 0, 1]
```

Здесь TP = 3, TN = 2, FP = 0, FN = 1.
Accuracy = `5/6`, precision = `3/3`, recall = `3/4`, F1 = `6/7`.

| Метрика | Результат | scikit-learn |
|---|---:|---:|
| Accuracy | 0.833333 | 0.833333 |
| Precision | 1.000000 | 1.000000 |
| Recall | 0.750000 | 0.750000 |
| F1 | 0.857143 | 0.857143 |

Матрица ошибок — `[[2, 0], [1, 3]]`.
Строки соответствуют реальным классам, столбцы — прогнозам, порядок классов `[0, 1]`.

## Входные данные и тесты

Массивы должны быть одномерными, непустыми, одинаковой длины, без NaN и бесконечностей.
Для R² нужны хотя бы два наблюдения. При постоянном `y_true` возвращается 1 для точного
прогноза и 0 в остальных случаях — как в scikit-learn с `force_finite=True`.
При нулевом знаменателе precision, recall и F1 возвращают 0; можно задать `zero_division=1`.

81 тест проверяет сравнение со scikit-learn, случайные данные, граничные случаи
и обработку неверных входов. Допуск сравнения — `rtol=1e-12`, `atol=1e-12`.
В вычислениях используется NumPy; scikit-learn нужен для примеров и тестов.

## Запуск

Python 3.12. Команды для PowerShell из папки `ml-metrics-from-scratch`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -q
python examples.py
```

В Linux и macOS окружение активируется командой `source .venv/bin/activate`.

`examples.py` выводит сравнение всех восьми метрик в терминал и проверяет матрицу ошибок.
При импорте функций из своего скрипта добавьте папку `src` в `PYTHONPATH`.
